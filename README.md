# PROJECT ZERO — Mobile FPS Prototype

Первый браузерный прототип мобильного tactical FPS.
Открывается локально в браузере: `index.html`.

Управление:
- WASD / виртуальный левый стик — движение
- мышь / правый стик — обзор
- ЛКМ / FIRE — стрельба
- R / RELOAD — перезарядка
- SHIFT — ускорение
- 1/2 — смена оружия

Это vertical slice: движение, камера, стрельба, мишени, HUD, раунд и мобильные touch-контролы.
